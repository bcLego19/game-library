Game Library

🚀 Welcome to the Retro Game Library

This repository hosts a collection of classic arcade games built entirely using modern, dependency-free web technologies (HTML, CSS, and vanilla JavaScript). The primary goal of this project is to demonstrate robust, single-file application development, focusing on high performance, clean game logic, and exceptional cross-device responsiveness.

The currently featured game, Classic Pong, is fully playable on desktop, tablet, and mobile devices, utilizing an adaptive design that maintains a perfect aspect ratio regardless of screen size.

Core Technologies Used

HTML5 Canvas: For high-performance, frame-by-frame game rendering.

Vanilla JavaScript: For all game logic, physics, and state management.

CSS & Media Queries: For defining the modern aesthetic and ensuring full responsiveness across all breakpoints.
